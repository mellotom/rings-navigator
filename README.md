# rings-navigator

travelers guide for synthesizing nature: a one-page reference for the mutable instruments rings resonator, firmware 1.1. the three resonators and their hidden twins, what plays the string, polyphony, the disastrous peace easter egg, LED codes and calibration, with diagrams.

live page: https://mellotom.github.io/rings-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

compiled from the mutable instruments rings manual, firmware notes and secrets page (https://pichenettes.github.io/mutable-instruments-documentation/modules/rings/) and the open-source rings firmware. not affiliated with mutable instruments.
